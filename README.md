# SVM Cats vs Dogs Classifier

A Machine Learning project that classifies Cats and Dogs using Support Vector Machine (SVM) with HOG feature extraction and PCA dimensionality reduction.

---

## 📌 Features

* HOG (Histogram of Oriented Gradients) feature extraction
* PCA dimensionality reduction
* SVM with RBF kernel
* Hyperparameter tuning using GridSearchCV
* ROC Curve and AUC evaluation
* Confusion matrix visualization
* PCA scatter plots
* Decision boundary visualization
* Full analytics dashboard

---

## 🛠 Technologies Used

* Python
* NumPy
* Matplotlib
* Scikit-learn
* Pillow (PIL)

---

## 📊 Project Workflow

1. Load image dataset
2. Resize images to 64×64
3. Extract HOG features
4. Apply feature scaling
5. Reduce dimensions using PCA
6. Train SVM classifier
7. Tune hyperparameters using GridSearchCV
8. Evaluate model performance
9. Generate visual dashboard

---

## 🚀 How to Run

Install required libraries:

```bash
pip install numpy matplotlib pillow scikit-learn
```

Run the project:

```bash
python svm_cats_dogs.py
```
